# Data Directory

Place the dataset in this folder locally before running the notebook.

Expected structure:

```text
data/
└── o-vs-r-split/
    ├── train/
    │   ├── O/
    │   └── R/
    └── test/
        ├── O/
        └── R/
```

This directory is excluded from Git, so image files stay local and are not uploaded with the repository.
