# Notebooks

This directory preserves the project notebook for reproducibility, provenance,
and inspection of the stored training outputs.

The maintained public surface of the repository is the bundled checkpoint,
`predict.py`, and the supporting project metadata and test tooling.

The root `.gitattributes` file marks `notebooks/**` as `linguist-vendored` so
archived notebook material does not define GitHub's language classification for
the maintained repository.
